# CSS email

## Versione SCSS

Richiede `sass`, compilazione in `templates/email/css/`:

```bash
npm i -D sass
```

```bash
npm run 'email sass'
```

## Versione PostCSS


```bash
npm i -D postcss postcss-cli postcss-import postcss-nested postcss-custom-properties autoprefixer cssnano
```

```bash
npm run 'postcss email'
```
